# Quantum-interconnect-for-Nickel-oxide-NiO

#### This repository contained, the Qutip code for research work title: "First-Principles and Open Quantum Dynamics of Sub-Nanosecond Terahertz Quantum Interconnects via NiO Antiferromagnetic Magnon Buses" which is posted in Research gate with DOI : https://doi.org/10.13140/RG.2.2.24710.33600. The Qutip-code folder contained 3 python file 1) resonance.py 2) master.py 3) dispersive.py . 

#### resonance.py contained the Qutip simulation code for resonance condition where qubit frequency is equal to magnon resonance frequency

#### master.py contained the Qutip simulation code for ope-quantum simulation using master equation 

#### dispersive.py contained Qutip simulation code where qubit frequency reduced to 980 GHz and keep magnon resonance 1.0 THz
